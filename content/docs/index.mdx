# Introduction to ClickORM

ClickORM is a type-safe ORM for ClickHouse with intuitive APIs.

## Features

- **Type-safe** - Full TypeScript support with type inference
- **Intuitive API** - Easy to use query builder
- **Powerful** - Support for complex queries and relations
- **Flexible** - Works with any ClickHouse setup

## Quick Start

Get started with ClickORM in minutes.

```typescript
import { ClickORM } from 'clickorm'

const orm = new ClickORM({
  host: 'localhost',
  port: 8123,
})
