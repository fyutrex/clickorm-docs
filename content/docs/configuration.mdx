# Configuration

Learn how to configure ClickORM for different environments and use cases.

## Basic Configuration

### Client Configuration

```typescript
import { ClickORM } from '@clickorm/core';

const orm = new ClickORM({
  host: 'localhost',
  port: 8123,
  database: 'myapp',
  username: 'default',
  password: '',
});
```

### Environment Variables

Create a `.env` file:

```bash
# Database Connection
CLICKHOUSE_HOST=localhost
CLICKHOUSE_PORT=8123
CLICKHOUSE_DATABASE=myapp
CLICKHOUSE_USERNAME=default
CLICKHOUSE_PASSWORD=secret

# Application
NODE_ENV=development
DEBUG=true
```

Load configuration from environment:

```typescript
import { ClickORM } from '@clickorm/core';
import dotenv from 'dotenv';

dotenv.config();

export const orm = new ClickORM({
  host: process.env.CLICKHOUSE_HOST!,
  port: Number(process.env.CLICKHOUSE_PORT),
  database: process.env.CLICKHOUSE_DATABASE!,
  username: process.env.CLICKHOUSE_USERNAME!,
  password: process.env.CLICKHOUSE_PASSWORD!,
  debug: process.env.DEBUG === 'true',
});
```

## Configuration Options

### Connection Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `host` | string | Required | ClickHouse server hostname |
| `port` | number | `8123` | HTTP interface port |
| `database` | string | `'default'` | Default database name |
| `username` | string | `'default'` | Authentication username |
| `password` | string | `''` | Authentication password |
| `protocol` | `'http' \| 'https'` | `'http'` | Connection protocol |

```typescript
const orm = new ClickORM({
  host: 'clickhouse.example.com',
  port: 8443,
  protocol: 'https',
  database: 'analytics',
  username: 'admin',
  password: 'secure-password',
});
```

### Performance Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `poolSize` | number | `10` | Connection pool size |
| `poolMin` | number | `2` | Minimum pool connections |
| `poolMax` | number | `20` | Maximum pool connections |
| `timeout` | number | `30000` | Query timeout (ms) |
| `compression` | boolean | `false` | Enable HTTP compression |

```typescript
const orm = new ClickORM({
  host: 'localhost',
  poolSize: 50,
  poolMin: 10,
  poolMax: 100,
  timeout: 60000,
  compression: true,
});
```

### Debug Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `debug` | boolean | `false` | Enable debug logging |
| `logQueries` | boolean | `false` | Log all SQL queries |
| `logErrors` | boolean | `true` | Log errors |

```typescript
const orm = new ClickORM({
  host: 'localhost',
  debug: process.env.NODE_ENV === 'development',
  logQueries: true,
  logErrors: true,
});
```

### Retry Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `maxRetries` | number | `3` | Maximum retry attempts |
| `retryDelay` | number | `1000` | Delay between retries (ms) |
| `retryOn` | function | - | Custom retry condition |

```typescript
const orm = new ClickORM({
  host: 'localhost',
  maxRetries: 5,
  retryDelay: 2000,
  retryOn: (error) => {
    // Retry on network errors
    return error.code === 'ECONNRESET';
  },
});
```

## ClickHouse Settings

### Global Settings

Configure ClickHouse-specific settings:

```typescript
const orm = new ClickORM({
  host: 'localhost',
  settings: {
    // Performance
    max_threads: 8,
    max_memory_usage: 10000000000,
    
    // Timeouts
    max_execution_time: 60,
    connect_timeout: 10,
    receive_timeout: 300,
    send_timeout: 300,
    
    // Query behavior
    join_use_nulls: 1,
    enable_http_compression: 1,
    
    // Optimization
    max_insert_block_size: 1048576,
    min_insert_block_size_rows: 1048576,
  },
});
```

### Common Settings

#### Memory Settings

```typescript
const orm = new ClickORM({
  host: 'localhost',
  settings: {
    max_memory_usage: 10000000000, // 10GB
    max_bytes_before_external_group_by: 5000000000,
    max_bytes_before_external_sort: 5000000000,
  },

```

#### Thread Settings

```typescript

  host: 'localhost',
  settings: {
    max_threads: 4,
    max_insert_threads: 4,
    max_read_buffer_size: 10485760,

```

#### Timeout Settings


## SSL/TLS Configuration

### Basic SSL

```typescript

  host: 'secure.clickhouse.com',
  port: 8443,
  protocol: 'https',
  ssl: {
    rejectUnauthorized: true,
  },
});
```

### Certificate Authentication

```typescript
import fs from 'fs';

const orm = new ClickORM({
  host: 'secure.clickhouse.com',
  protocol: 'https',
  ssl: {
    ca: fs.readFileSync('ca.pem'),
    cert: fs.readFileSync('client-cert.pem'),
    key: fs.readFileSync('client-key.pem'),
    rejectUnauthorized: true,
  },
});
```

### Configuration Loader

```typescript
// config/index.ts
import development from './development';
import production from './production';
import { ClickORM } from '@clickorm/core';

const configs = {
  development,
  production,
};

const env = process.env.NODE_ENV || 'development';
const config = configs[env as keyof typeof configs];

export const orm = new ClickORM(config);
```

```typescript

  // Pool settings
  poolSize: 20,
  poolMin: 5,
  poolMax: 50,
  poolIdleTimeout: 30000,
  poolAcquireTimeout: 10000,
```

### Pool Events

```typescript
orm.pool.on('acquire', (connection) => {
  console.log('Connection acquired from pool');
});

orm.pool.on('release', (connection) => {
  console.log('Connection released to pool');

orm.pool.on('error', (error) => {
  console.error('Pool error:', error);
});
```

## Logging Configuration

### Custom Logger

```typescript
const orm = new ClickORM({
  host: 'localhost',
  logger: {
    log: (message: string) => console.log(`[ORM] ${message}`),
    error: (message: string) => console.error(`[ORM ERROR] ${message}`),
    warn: (message: string) => console.warn(`[ORM WARN] ${message}`),
    debug: (message: string) => console.debug(`[ORM DEBUG] ${message}`),
  },
});
```

### Winston Integration

```typescript
import winston from 'winston';

const logger = winston.createLogger({
  level: 'info',
  format: winston.format.json(),
  transports: [
    new winston.transports.File({ filename: 'error.log', level: 'error' }),
    new winston.transports.File({ filename: 'combined.log' }),
  ],
});

const orm = new ClickORM({
  host: 'localhost',
  logger: {
    log: (msg) => logger.info(msg),
    error: (msg) => logger.error(msg),
    warn: (msg) => logger.warn(msg),
    debug: (msg) => logger.debug(msg),
  },
});
```

### Middleware

```typescript
const orm = new ClickORM({
  host: 'localhost',
  middleware: {
    beforeQuery: async (sql, params) => {
      console.log('Executing:', sql);
      return { sql, params };
    },
    afterQuery: async (result) => {
      console.log('Result rows:', result.length);
      return result;
    },
  },
});
```

## Best Practices

### 1. Use Environment Variables

Store sensitive data in environment variables:

```bash
# .env
CLICKHOUSE_HOST=production.clickhouse.com
CLICKHOUSE_USERNAME=admin
CLICKHOUSE_PASSWORD=secure-password
```

### 2. Separate Configurations

Maintain separate configs for each environment:

```
config/
├── development.ts
├── production.ts
├── staging.ts
└── test.ts
```

### 3. Connection Pooling

Configure appropriate pool sizes:

```typescript
const orm = new ClickORM({
  host: 'localhost',
  poolSize: Math.max(10, require('os').cpus().length),
});
```

### 4. Timeouts

Set reasonable timeouts:

```typescript
const orm = new ClickORM({
  host: 'localhost',
  timeout: 30000, // 30 seconds
  settings: {
    max_execution_time: 300, // 5 minutes
  },
});
```

### 5. Error Handling

Configure proper error handling:

```typescript
const orm = new ClickORM({
  host: 'localhost',
  onError: (error) => {
    console.error('Database error:', error);
    // Send to error tracking service
    errorTracker.captureException(error);
  },
});
```

## Troubleshooting

### Connection Issues

```typescript
const orm = new ClickORM({
  host: 'localhost',
  debug: true, // Enable debug logging
  timeout: 10000, // Reduce timeout for faster failure
});

// Test connection
orm.on('error', (error) => {
  console.error('Connection error:', error);
});

await orm.ping();
```

### Performance Issues

```typescript
const orm = new ClickORM({
  host: 'localhost',
  settings: {
    max_threads: 16, // Increase threads
    max_memory_usage: 20000000000, // Increase memory
  },
  poolSize: 100, // Increase pool size
  compression: true, // Enable compression
});
```
